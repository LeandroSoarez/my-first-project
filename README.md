# Minha primeira página

Cartão de apresentação pessoal, meu primeiro projeto publicado na web.

**Ver no ar:** https://my-first-project-tau-rust.vercel.app

## O que tem

- Cartão centralizado na tela com nome, cargo e uma frase de apresentação

## Tecnologias

- HTML
- CSS

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.
